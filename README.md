# PoE Radar – Releases

Fertige Pakete des PoE-Radar-Overlays (Path of Exile 1). Der Quellcode liegt nicht hier.

- Neueste Version: [Releases](../../releases/latest) → `PoERadar-klein.zip`
- Benötigt einmalig die **.NET Desktop Runtime 10 (x64)**.
- Entpacken, `2-Overlay-starten.cmd` starten. Danach aktualisiert sich das Paket bei jedem Start selbst
  (liest `update.json` in diesem Repo); Einstellungen und Profile bleiben erhalten.

Hinweis: Ein Map-Revealer verstößt gegen die Nutzungsbedingungen von Grinding Gear Games. Das Risiko
einer Kontosperre trägt, wer das Programm benutzt.
